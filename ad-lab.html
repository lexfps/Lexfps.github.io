Windows Server Active Directory Lab

I designed and configured a virtual Windows Server environment using Oracle VirtualBox to gain hands-on experience with Active Directory Domain Services, user account administration, Group Policy, domain authentication, and Windows security controls.

← Back to Portfolio View Screenshots

Project Overview

This project simulates a small business Active Directory environment. I installed Windows Server, configured Active Directory Domain Services and DNS, created and managed domain users, applied account security policies, and tested domain authentication.

The purpose of the lab was to develop practical Windows administration skills commonly used in help desk, desktop support, system administration, and IT support positions.

Technologies Used

Windows Server 2022 Oracle VirtualBox Active Directory Active Directory Domain Services DNS Group Policy Windows Client Command Prompt

Skills Demonstrated

  • Installed and configured Windows Server 2022 in Oracle VirtualBox.
  • Installed Active Directory Domain Services and promoted the server to a domain controller.
  • Configured DNS services for the Active Directory domain.
  • Created and managed domain user accounts.
  • Configured password complexity and password expiration requirements.
  • Configured account lockout policies to improve security.
  • Applied logon-hour restrictions to user accounts.
  • Disabled, locked, unlocked, and restored user accounts.
  • Tested domain authentication using a Windows client.
  • Verified domain users through Command Prompt.

Challenges and Solutions

Applying Security Policies

One challenge was understanding how domain policies affect user accounts and authentication. I reviewed the Group Policy settings, updated the policies, tested the user account behavior, and confirmed whether each policy worked as expected.

Testing Account Lockout

I tested the account lockout policy by intentionally entering incorrect credentials. After confirming that the account became locked, I used Active Directory Users and Computers to restore access.

What I Learned

This project strengthened my understanding of Active Directory administration, Windows Server management, enterprise authentication, account security, and Group Policy.

I also gained more confidence navigating Windows Server tools, troubleshooting account access, and documenting technical work in a way that can be understood by other IT professionals.
